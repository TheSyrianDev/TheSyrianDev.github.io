The goal

Capable AI that a person owns instead of rents. It is a simple thing to say and a slow thing to build, so the work is chopped into pieces that each have to stand on their own.

  • 01 A whole stack on your desk. The downloader pulls the weights, the engine runs them, the harness runs the turns, the studio is where you work. Four parts, one install, no service in the middle.
  • 02 Nothing rented. Loopback is the bus. The only network calls are the ones a request you made implies: a provider you added, a download you started, a search you asked for.
  • 03 Readable, portable knowledge. Memory and roles are Markdown, looks are a folder. What the machine concluded about you is a file you can open, edit or delete, and the whole of it moves to a new laptop by copying one directory.
  • 04 Parts that stand alone. Somebody should use the downloader and never hear of the studio; somebody should run the harness against their own server. A bundle that only works as a bundle is a lock.
  • 05 Honest about the state. Every README names the version and the gaps. No benchmarks I did not run, no screenshots I did not take, no "production ready" on alphaware.

LastSoft company

LastSoft makes tools that keep AI on the machine it runs on. The products are Last AI and the three parts beneath it — LastHarness, LastEngine and hf-dl — each useful alone, each source-available. Projects

Four parts of one suite. Each repository is its own thing, with its own release and its own limits.

  • Last AI

    The studio. A desktop app and a terminal client over a local core: conversations, memory, tools, a team of departments and workers, spend limits.

    0.1.0-alpha.3
  • LastHarness

    The harness underneath. Give it a model and a goal and it runs the turn loop: prompt blocks, tool permissions, the team plan, the spend ledger. No downloader, no engine.

    own repo
  • LastEngine

    Inference, clean-room, in Rust. One backend trait — CUDA first, then CPU, Vulkan, ROCm and Metal — a hardware probe, and a server that speaks the local dialect.

    v0.1.0 · dev
  • hf-dl

    The model downloader. Models and datasets from the Hugging Face Hub and ModelScope, plus an opt-in Pirate Face route: segmented, resumable, verified transfers with a queue you can leave running and a lib crate you can embed.

    v0.4.0-rc.1
