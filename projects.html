Flagship · main project

Last AI

A local-first AI studio. A desktop app and a terminal client over a core that runs on your machine: conversations, memory, tools, a team of departments and workers, and spend limits that stop a run before it costs you anything.

The point is ownership: loopback is the bus, the only network calls are the ones a request you made implies, memory and roles are Markdown you can open, and what the machine concluded about you is a file you can edit or delete. Moving to a new laptop is copying a directory. It is pre-release software and every README names the gaps.

Under the hood

Parts that stand alone. Somebody should be able to use the downloader and never hear of the studio.

  • LastHarness

    The harness underneath. Give it a model and a goal and it runs the turn loop: prompt blocks, tool permissions, the team plan, the spend ledger. No downloader, no engine.

    own repo · lh / lastharness
  • LastEngine

    Inference, clean-room, in Rust. One backend trait — CUDA first, then CPU, Vulkan, ROCm and Metal — a hardware probe, and a server that speaks the local dialect.

    v0.1.0 · dev
  • Model-Downloader

    Models and datasets from the Hugging Face Hub and ModelScope, plus an opt-in Pirate Face route: segmented, resumable, verified transfers with a queue you can leave running and a lib crate you can embed.

    v0.4.0-rc.1 · mdl

How I build

  • Nothing rented. The work should still run when a service, an account or a connection goes away.
  • Readable, portable. State is files in a folder, in formats you already know.
  • Honest about the state. Version and gaps in every README. No benchmarks I did not run, no screenshots I did not take.
